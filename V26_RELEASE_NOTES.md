# V2.6 Release Notes
V2.6 connects V2.5 health/drift monitoring to Champion/Challenger governance.
- Healthy + valid evidence: eligible, approved risk preserved.
- Degraded health: demotion and 50% risk cap.
- Critical drift / blocked or unknown health: quarantine and zero risk.
- Invalid promotion evidence: quarantine and zero risk.
- Challenger cannot run LIVE.
- Shadow challengers have zero execution risk.
- Promotion requires explicit validated gates.
- Champion quarantine invalidates approval/evidence and zeroes risk.
- Single active champion invariant.

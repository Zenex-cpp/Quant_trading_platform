# V1.0 — Failure Injection Plan

Mandatory scenarios: invalid evidence, expired approval, gate invalidation, incompatible artifact, unknown position, stale data, reconciliation mismatch, kill activation, shadow order attempt, canary risk breach, challenger-live attempt, rollback failure, recovery-incomplete state and research-to-production permission violation.

Expected default behavior for new risk is BLOCK. Any exception must be explicit, versioned and audited.

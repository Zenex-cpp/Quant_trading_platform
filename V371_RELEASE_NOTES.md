# V3.71 Release Notes

V3.71 adds an application-level operational observability drill covering:

- monitoring heartbeat freshness;
- emergency alert delivery;
- acknowledgement deadlines;
- missed-acknowledgement escalation conditions;
- stale-heartbeat / silence detection;
- monitoring-unavailable fail-closed behaviour.

Evidence classification: `INTERNAL`.

This does not close the V3.59 monitoring/alerting operational evidence gap and does not constitute infrastructure monitoring, paging/SIEM, on-call, or production incident-response evidence.
